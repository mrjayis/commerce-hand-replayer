# Commerce hand replayer

Step through every hand from the Live at the Commerce PLO streams:
seats, hole cards, each action, both boards, and the winners, with a
"watch on YouTube" link that opens the stream at the start of each hand.

https://mrjayis.github.io/commerce-hand-replayer/

Filter to one player's hands with the player menu (shareable:
`#p=TONY`), and open any spot in the
[PLO equity calculator](https://mrjayis.github.io/plo-dbbp-equity-calculator/)
with the board so far and everyone still in.

Hand histories are read automatically from the stream overlay, so an
occasional card or action may be off. Deep-link a hand with `#h=<hand>`.
